# Checkpoint 1 - Application Development

Calculadora de IMC (Índice de Massa Corporal) desenvolvida como parte do Checkpoint 1 da disciplina de Application Development (FIAP).

## 🔗 Acesse o projeto rodando

Como o GitHub Pages não é usado aqui, a visualização é feita pelo html-preview:

**[Clique aqui para ver o projeto funcionando](https://html-preview.github.io/?url=https://raw.githubusercontent.com/gustavofranzoti/checkpoint1-AD/main/index.html)**

## 📋 Sobre o projeto

O app calcula o IMC do usuário a partir do peso e da altura informados, e classifica o resultado em uma das quatro faixas:

- Abaixo do peso
- Peso normal
- Sobrepeso
- Obesidade

## 🛠️ Tecnologias utilizadas

- **HTML** - estrutura da página (`index.html`)
- **CSS** - estilos, seletores, box model, grid e responsividade (`style.css`)
- **JavaScript** - lógica de cálculo do IMC (`script.js`)

## 📁 Estrutura dos arquivos

```
├── index.html   → estrutura da página
├── style.css    → estilos e layout responsivo
└── script.js    → função de cálculo do IMC
```

## ▶️ Como rodar localmente

1. Clone este repositório
2. Abra a pasta no VS Code
3. Clique com o botão direito em `index.html` e selecione "Open with Live Server"
